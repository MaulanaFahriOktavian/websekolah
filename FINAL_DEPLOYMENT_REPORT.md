## Production Environment Configuration

### Critical Settings (from .env)
- **APP_ENV**: `production` (NOT `local`)
- **APP_DEBUG**: `false` (NOT `true` - prevents secret leakage)
- **APP_URL**: `https://yourdomain.com` (HTTPS required)
- **APP_KEY**: Generated by `php artisan key:generate`

### Database Drivers Supported
1. **SQLite** - Default, suitable for small schools (≤500 users)
2. **MySQL 8.0+** - Recommended for production (medium to large)
3. **PostgreSQL 14+** - Best reliability (mission-critical)
4. **MariaDB 10.7+** - MySQL-compatible alternative
5. **SQL Server** - Enterprise option

### Storage & Service Configuration
- **Sessions**: Database-backed (requires `sessions` table)
- **Cache**: Database-backed (requires `cache` table)
- **Queue**: Database-backed (requires `jobs` table)
- **File Upload**: Local filesystem with public symlink
- **Mail**: Configurable (SMTP, Sendmail, or log in dev)

## Deployment Phases

### Phase A: First-Time Server Setup (One-Time)
**Estimated Time**: 30–60 minutes

**Commands**:
1. Provision OS (Ubuntu 20.04+ / Debian 11+)
2. Install PHP 8.3+, Node 18+, MySQL/PostgreSQL
3. Create database and user
4. Clone code to `/var/www/sekolah`
5. Install PHP dependencies via Composer
6. Install Node dependencies and build frontend
7. Copy `.env.example` → `.env` and configure
8. Generate `APP_KEY` via `php artisan key:generate`
9. Run migrations: `php artisan migrate --force`
10. Seed data: `php artisan db:seed --force`
11. Create storage symlink: `php artisan storage:link`
12. Configure web server (Apache/Nginx)
13. Install SSL certificate (LetsEncrypt)

### Phase B: Per-Deployment (Every Release)
**Estimated Time**: 5–10 minutes

**Commands**:
1. Pull latest code: `git pull origin main`
2. Install dependencies: `composer install --optimize-autoloader --no-dev`
3. Build frontend: `npm install && npm run build`
4. Clear caches: `php artisan cache:clear` + config + route cache
5. Verify: Test HTTPS access, check logs

### Phase C: Database Schema Migration (When Schema Changes)
**Only if new migrations added**

**Commands**:
1. Backup database first
2. Run migrations: `php artisan migrate --force`
3. Verify: Check migration status
4. Seed if needed: `php artisan db:seed` (for new seeders only)
